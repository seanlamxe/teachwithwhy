# 教得有據 · TeachWithWhy｜使用說明

版本 0.4 · 香港小學及中學教師適用 · 主要供電腦使用

## 由課題到活動，只需三步

1. **填寫課題**：首頁直接填寫年級、科目、人數、活動時間、課題、學生基礎及困難、可觀察的學習目標，再選支援安排。原有問題均保留並直接顯示。
2. **生成並修改**：確認沒有加入學生個人資料並同意 AI 處理，按「生成課堂活動」。毋須先比較方法或閱讀策略庫。
3. **使用活動**：核對內容及來源，修改文字，再複製到教案、列印／另存 PDF 或儲存。課後回顧屬選用。

目前教師免費使用，不需註冊、試用碼或自己提供 API Key。模型由網站管理員一次接入，並受服務額度及使用頻率限制。

## 每份活動有甚麼？

- 老師原先填寫的學習目標，以及活動怎樣對應目標。
- 開始前的先備知識檢查。
- 按分鐘安排的活動步驟。
- 可直接使用的教師提問與句式。
- 學生可跟從的任務說明。
- 對應目標的形成性評估，附可觀察的表現。
- 簡單記錄方式，以及繼續、調整或轉換方法的參考準則。
- 材料、支援安排及研究說明。

以上內容仍是草稿，請按班內學生需要核對修改。現時產品聚焦課堂參與、小組討論及解釋理由，不是完整校本課程系統。

## 一個高小例子

選「高小」「中國語文」、30 人、12 分鐘；課題填「《龜兔賽跑》人物行為與理由」。學生基礎及困難填「能說出人物特點，但未能引用行為解釋看法」。目標填「引用故事中的一個行為，解釋對人物的看法」。選好支援安排後生成。

教師可把提問改成：「兔子在哪一段行為顯得輕敵？請指出故事中的例子。」學生任務可要求寫出「我認為……，因為文中提到……」。用最後一分鐘檢查每位同學是否有提供例子。

這是使用方法的說明，不代表本例已成功經 AI API 生成或在課堂驗證。

## 研究依據放在哪裏？

不再設獨立的靜態策略庫。在活動內展開「為甚麼建議這個安排？」即可看到：研究提到甚麼、這次怎樣改編、有哪些局限及原始連結。

研究發現與 AI 的活動改編分開標示；來源綜述不代表已驗證這份具體活動。

## AI 與示範活動

- 「先試示範活動」是固定規則內容，會明確標示「不是 AI 結果」，不消耗模型額度。
- 真正 AI 活動會列出模型、生成時間及來源模式。未設定密鑰時不能真實生成。
- 直接 DeepSeek／OpenAI 模式可聯網搜尋；Gateway 模式嘗試即時讀取已收錄研究頁面。
- 如 Gateway 未能讀取頁面，會使用已核對摘要，並標示沒有完成即時讀取。
- 額度不足或服務出錯時會明確提示，不會把示範內容冒充 AI 結果。

## 儲存、備份與語言

「已儲存活動」可再次開啟、回顧及下載備份。紀錄只存於目前瀏覽器，不會自動跨裝置同步。新版接受舊名稱的備份；不同網址需自行匯入。刪除活動亦會刪除該次回顧。

右上角在同一網址切換香港繁體中文及英文，不會翻譯已儲存的原始內容。

## 私隱及管理員接入

請勿加入學生姓名、聯絡資料或診斷報告。AI 只處理你同意提交的內容；分析課後回顧會另行確認。供應商資料政策另行適用。

網站管理員可按 [DeepSeek 官方開通步驟](deepseek-setup-zh.md) 設定一次密鑰，教師毋須自行設定。免費供教師使用，不代表模型供應商無限免費；管理員須核對帳戶額度及預算。

## 教學設計原則

先確定學習目標，再安排能顯示理解的任務和檢查，最後設計活動步驟與支援。AI 不會自行替換老師的目標。若目標過大，草稿應說明限制。

課後對照原先的準則記錄觀察；回顧頁會顯示這些準則。參與人數不等於學會了多少，一次觀察亦不能證明因果。判斷準則屬可修改的建議，並非經驗證的分數門檻。此設計參考[教育局「促進學習的評估」](https://www.edb.gov.hk/en/curriculum-development/assessment/about-assessment/assessment-for-learning.html)的回饋與調整教學原則，並不表示教育局認證本產品。
